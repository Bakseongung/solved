```
집합의 discard 기능을 사용하여 풀이하였다.
remove는 집합의 원소가 없는 상태에서 같은 원소를 삭제하면 에러가 발생하지만,
discard는 집합의 원소가 없는 상태에서 원소를 제거해도 오류를 일으키지 않는다.
```
```
시간복잡도	O(N+M), 공간복잡도	O(N)
```
``` py
N,M=map(int,input().split())
cnt=0
a=set()
for i in range(1,N+1):
	a.add(i)

for _ in range(M):
	b=int(input())
	cnt+=1
	if b in a:
		a.discard(a)
		if a=={}:
			print(cnt)
print(-1)
```
