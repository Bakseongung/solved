```
끝나는 시간이 먼저 빨라야, 다음 행사를 많이 찾을 수 있기 때문에,
끝나는 시간 먼저 정렬 후, 그다음 시작 시간을 정렬하였다.
행사가 끝나면, 1의 시간이 지나야 되기 때문에 if a>=end 가 아니라
if a>end로 풀이하였다.
```
```py
n=int(input())
lst=[]
for i in range(n):
    temp=list(map(int,input().split()))
    lst.append(temp)
lst.sort(key=lambda x: (x[1],x[0]))
#print(lst)

cnt=0
end=0

for a,b in lst:
    if a>end: 
        cnt+=1
        end=b
print(cnt)
```
